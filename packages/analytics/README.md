# Analytics

Package Dart réservé à la future frontière d'analytics locale de SAMTECH.

## Statut Sprint 0

Aucune API ni logique métier n'est implémentée. Le package réserve uniquement le nom et la frontière architecturale ; il n'effectue aucune collecte ni télémétrie.

## Responsabilités envisagées

- événements locaux minimisés ;
- métriques de performance ;
- aucun envoi distant par défaut dans l'édition Starter.

Ces responsabilités restent non contractuelles jusqu'à leur cadrage et leur validation.
