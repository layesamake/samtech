# Notifications

Package Dart réservé à la future frontière de notifications locales de SAMTECH.

## Statut Sprint 0

Aucune API, planification ni intégration native n'est implémentée. Le package réserve uniquement le nom et la frontière architecturale.

## Responsabilités envisagées

- planification locale ;
- gestion des permissions ;
- gestion des fuseaux horaires ;
- réconciliation au redémarrage.

Les adaptateurs Flutter/natifs seront séparés du modèle Dart après validation du spike notifications.
