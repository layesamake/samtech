# UI Kit

Design system SAMTECH — tokens documentés et thème clair Material 3.

## Statut

Sprint 0 : tokens et thème fondationnel implémentés.

## Contenu

### Tokens

- **Couleurs** — variantes claires/sombres pour la marque, les surfaces et le texte ; couleurs sémantiques partagées
- **Espacement** — grille base 4pt
- **Rayons** — small (8), medium (12), large (16), full (999)
- **Typographie** — 8 styles utilisant la police système

### Thème

- Thème clair Material 3 avec couleurs et typographies SAMTECH
- Tokens sombres préparés, sans `ThemeData` sombre livré avant validation

## Principes

- Aucun style arbitraire dans les écrans
- Les écrans utilisent les tokens du `ui_kit`
- Indépendant du domaine métier CRM
- Conforme à `docs/04_DESIGN/DESIGN_SYSTEM.md`
