# Backup

Package Dart réservé à la future frontière de sauvegarde et restauration de SAMTECH.

## Statut Sprint 0

Aucune API ni logique de sauvegarde n'est implémentée. Le package réserve uniquement le nom et la frontière architecturale.

## Responsabilités envisagées

- enveloppe chiffrée avec manifeste versionné ;
- validation d'intégrité ;
- restauration atomique ;
- portabilité Android/iOS.

Ces responsabilités dépendent du spike de sauvegarde et de la stratégie de chiffrement.
