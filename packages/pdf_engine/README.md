# PDF Engine

Package Dart réservé à la future frontière de génération documentaire de SAMTECH.

## Statut Sprint 0

Aucune API ni génération PDF n'est implémentée. Le package réserve uniquement le nom et la frontière architecturale.

## Responsabilités envisagées

- moteur de documents PDF ;
- gestion des polices et de la pagination ;
- tests visuels de rendu ;
- réception de modèles de documents figés.

Le moteur et ses éventuels adaptateurs Flutter seront choisis après validation technique.
