# License Manager

Package Dart réservé à la future frontière de gestion des licences SAMTECH.

## Statut Sprint 0

Aucune API, vérification cryptographique ni logique de licence n'est implémentée. Le package réserve uniquement le nom et la frontière architecturale.

## Responsabilités envisagées

- modèle de licence et machine d'états ;
- vérification de signature asymétrique ;
- période de grâce offline ;
- client d'activation abstrait.

Le protocole et les primitives devront être validés par les spikes de sécurité et de licence.
