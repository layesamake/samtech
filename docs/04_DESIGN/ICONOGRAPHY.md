## 1. Bibliothèque

Utiliser en priorité les icônes Material Symbols ou les équivalents Cupertino lorsqu'une convention native forte le justifie. Toute bibliothèque supplémentaire doit avoir une licence compatible et être documentée.

## 2. Principes

- Une icône seule est réservée aux conventions largement comprises et possède toujours un libellé accessible.
- Une action financière, destructive ou liée à la licence conserve un libellé visible.
- Les icônes partagent un poids et une taille cohérents dans une même zone.
- Une marque WhatsApp officielle n'est utilisée que conformément à ses règles de marque ; une icône générique de message peut être préférable.
- Les emojis ne servent pas d'icônes produit finales.

## 3. Tailles

| Contexte | Taille visuelle indicative | Cible tactile minimale |
|---|---:|---:|
| Navigation | 24 | 48 |
| Action de barre | 24 | 48 |
| Puce ou statut | 16–18 | composant complet 44–48 |
| Illustration d'état | 48–80 | non interactive |

## 4. Mappage conceptuel

| Concept | Icône recommandée | Libellé visible requis |
|---|---|---|
| Accueil | maison | navigation oui |
| Contacts | personnes | navigation oui |
| Relances | calendrier/coché | navigation oui |
| Ventes | reçu/document | navigation oui |
| Plus | grille/menu | navigation oui |
| Prospect | personne ajoutée | selon contexte |
| Client | badge/personne validée | si ambigu |
| WhatsApp/message | bulle sortante | oui pour l'action |
| Facture | reçu long | oui |
| Paiement | portefeuille/monnaie | oui |
| Sauvegarde | archive/flèche sortante | oui |
| Restauration | archive/flèche entrante | oui |
| Licence | clé/badge | oui |
| Retard | horloge avec alerte | texte « En retard » |
| Succès | coche cerclée | message de succès |
| Erreur | alerte cerclée | message d'erreur |
| Archive | boîte archive | confirmation selon impact |
| Supprimer | corbeille | toujours |

## 5. États

Les icônes interactives définissent normal, pressé, focus et désactivé. Une icône désactivée conserve un contraste suffisant et une explication si l'utilisateur peut raisonnablement chercher l'action.

## 6. Interdictions

- Ne pas distinguer payé/impayé par une icône ou couleur seule.
- Ne pas utiliser deux icônes différentes pour le même concept selon les modules.
- Ne pas utiliser une icône « envoyer » si l'action ne fait qu'ouvrir WhatsApp sans envoyer.
- Ne pas utiliser un cadenas pour représenter à la fois PIN, licence et sauvegarde chiffrée sans libellé.
